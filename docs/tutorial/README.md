## 写什么

- 从零开始，**一步步**带你完成一个完整任务
- 每一步都到“我能照着做”的颗粒度（命令、点击、期望结果）
- **不**假设你已经懂 evorule 的任何概念

## 不要写在这里

- ❌ “怎么解决 X 问题” → 去 [how-to/](../how-to/)
- ❌ API 字典、字段说明 → 去 [reference/](../reference/)
- ❌ “为什么这么设计” → 去 [explanation/](../explanation/)

## 命名规范

`NN-标题.md`（如 `01-quickstart.md`），NN 从 01 起，保证学习顺序。
